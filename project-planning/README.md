# Project Planning

Use this skill when coordinating a project from kickoff through delivery.

## Core abilities
- Define scope, milestones, and success criteria
- Break work into manageable tasks and owners
- Create schedules and dependencies
- Track risks, blockers, and progress updates

## Suggested workflow
1. Clarify the desired outcome and constraints.
2. Identify major deliverables and dependencies.
3. Assign owners and target dates.
4. Review status regularly and adjust priorities as needed.

## Example prompt
"Create a project plan for a five-week marketing campaign with key milestones, responsibilities, and risks."
