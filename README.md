# Skills for Different Types of Management Tasks (including emails and website building etc.)

This repository collects practical skills for common management work, including email communication, website building, planning, and coordination.

## Included skills
- [Email Management](./email-management.md) — drafting, follow-ups, and professional communication
- [Website Building](./website-building.md) — landing pages, messaging, and structure for web projects
- [Project Planning](./project-planning.md) — scope, milestones, and action tracking
- [Team Coordination](./team-coordination.md) — meetings, updates, and stakeholder alignment

## Purpose
These skills help turn broad management tasks into clear, actionable workflows that can be reused across teams and situations.
