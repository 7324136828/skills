# Website Building

Use this skill when planning or improving a website for a business, project, or personal brand.

## Core abilities
- Define the audience, purpose, and key conversion goals
- Outline landing pages, calls to action, and messaging hierarchy
- Suggest content structure for home, about, services, and contact sections
- Recommend improvements for usability, clarity, and visual flow

## Suggested workflow
1. Identify the website goal and target audience.
2. Map the essential pages and user journey.
3. Draft headings, body copy, and CTAs.
4. Review mobile usability and information hierarchy.
5. Refine content based on business priorities.

## Example prompt
"Create a simple website outline for a consulting business, including homepage sections, services, testimonials, and a contact form."
